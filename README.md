# 📦 Laravel Product & Inventory Management

Sistem informasi berbasis web untuk mengelola master data produk, kategori barang, dan satuan unit menggunakan Laravel 11.

### 🛠️ Tech Stack
- **Framework**: Laravel 11
- **Database**: MySQL
- **Frontend**: Blade Template, Vite

### ✨ Fitur Utama
- Manajemen Produk & Stok Barang
- Manajemen Kategori dan Satuan Unit (*Units*)
- Autentikasi Pengguna
